# Plateforme Web d'Orientation pour Bacheliers

## Description
Cette plateforme web a été développée pour aider les nouveaux bacheliers à découvrir les différentes filières universitaires et à obtenir des informations utiles pour leur orientation académique.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- Responsive Design

## Fonctionnalités
- Présentation des filières universitaires
- Consultation des informations d'orientation
- Navigation simple et intuitive
- Interface utilisateur responsive adaptée aux ordinateurs et aux appareils mobiles

## Objectif du projet
Faciliter l'accès aux informations d'orientation universitaire et aider les étudiants à mieux comprendre les différentes options de formation disponibles.
